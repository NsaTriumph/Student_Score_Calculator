# Student Score Calculator

## Project Description
The Student Score Calculator is a simple web application that automatically calculates students' total scores and assigns grades based on their performance.

## Features
- Calculates scores for five students.
- Accepts three Continuous Assessment (CA) scores and one examination score.
- Automatically calculates total scores.
- Automatically assigns grades.
- Validates score entries.
- Supports decimal scores.
- Responsive table layout for smaller screens.

## Score Distribution

| Assessment | Maximum Score |
|---|---:|
| CA 1 | 10 |
| CA 2 | 10 |
| CA 3 | 10 |
| Examination | 70 |
| **Total** | **100** |

## Grading System

| Score | Grade |
|---|---|
| 70–100 | A |
| 60–69 | B |
| 50–59 | C |
| 45–49 | D |
| 40–44 | E |
| 0–39 | F |

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Files
- `index.html` – Webpage structure.
- `style.css` – Page styling and responsive design.
- `script.js` – Score calculations, grading and validation.

## How to Use
1. Open the webpage in a browser.
2. Enter each student's CA scores.
3. Enter the examination score.
4. View the automatically calculated total and grade.
